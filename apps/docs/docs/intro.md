# agentCourses API

agentCourses is a dark software factory scaffold. The first HTTP capability is the healthcheck, composed by `@apps/api` and served through the Hono route in `@axc/rest`.


The sample also provides [course search](./api/courses.md) and the [enrollment request workflow](./api/enrollment-requests.md). [Traceability](./traceability.md) maps requirements to automated evidence.
