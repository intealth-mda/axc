# agentCourses API

agentCourses is a dark software factory scaffold. `@apps/api` composes the Hono routes in `@axc/rest`.

- [Healthcheck](./healthcheck.md) reports that the API process is running.
- [Course catalog](./courses.md) searches the seeded training catalog.
- [Enrollment requests](./enrollment-requests.md) creates and reviews requests for active courses.
